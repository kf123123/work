# 车辆远程控制系统 — 上位机

基于 PyQt5 的车辆遥控上位机监控中心，通过 Wi-Fi 与 K230 下位机通信，实现实时视频监控、遥控驾驶、UWB 定位显示等功能。

---

## 系统架构

```
┌──────────────────────────────────┐     Wi-Fi     ┌─────────────────┐
│         上位机 (PC)              │ ◄──────────► │  下位机 (K230)  │
│                                  │               │                 │
│  主窗口 (main.py)                │    UDP 8080   │  摄像头推流      │
│    ├─ VideoReceiveThread  ◄──────┼───────────────┤  (k230.py)      │
│    ├─ TcpReceiveThread   ◄──────┼── TCP 8888    │                 │
│    ├─ 8方向控制按钮              │               │  运动控制执行器   │
│    ├─ 速度滑块                   │    TCP 控制   │  UWB 定位发送    │
│    └─ 定位小地图                 ├──────────────►│                 │
│                                  │   (JSON)      │                 │
└──────────────────────────────────┘               └─────────────────┘
```

### 通信方式

| 方向 | 协议 | 端口 | 用途 |
|------|------|------|------|
| K230 → PC | UDP | 8080 | 视频流（JPEG 分片传输） |
| PC → K230 | TCP | 8888 | 控制指令（JSON） |
| K230 → PC | TCP | 8888 | 定位数据（JSON, T=200） |

## 快速开始

### 环境依赖

```bash
pip install PyQt5 opencv-python numpy
```

### 本地测试（无需硬件）

**终端 1** — 启动上位机：
```bash
cd work/code
python main.py
```

**终端 2** — 启动视频模拟器（会生成动态测试画面）：
```bash
cd work/code
python test.py
```

### 连接真实硬件

1. 确保电脑与 K230 处于同一局域网
2. 修改 `main.py` 中的下位机 TCP 地址：
   ```python
   self.TARGET_IP = "192.168.x.x"   # K230 的 IP
   self.TARGET_PORT = 8888
   ```
3. 修改 `k230.py` 中的电脑 IP：
   ```python
   SERVER_IP = "192.168.x.x"        # 电脑的 IP
   ```
4. 先运行 `python main.py`，再启动 K230

## 控制方式

### 鼠标点击

D-pad 按钮布局：

```
         ↖左上    ↑前进    ↗右上
         ←左转    ■停止    →右转
         ↙左下    ↓后退    ↘右下
```

### 键盘控制

```
         Q   W   E
         A  空格  D
         Z   S   C
```

| 按键 | 动作 | T 值 |
|------|------|------|
| W | 前进 | 116 |
| S | 后退 | 117 |
| A | 左转 | 118 |
| D | 右转 | 119 |
| Q | 左上 | 120 |
| E | 右上 | 121 |
| Z | 左下 | 122 |
| C | 右下 | 123 |
| 空格 | 停止 | 115 |
| Q / Esc | 退出程序 | — |

### 速度控制

- 拖动滑块实时调整 PWM 值（0–200）
- 运动中调整速度 → 立即生效，自动重发当前指令

## 通信协议

### 控制指令（PC → K230, TCP JSON）

```json
{"T": 116, "pwm": 150}     // 前进，速度 150
{"T": 115}                 // 停止
{"T": 120, "pwm": 100}     // 左上前进
```

### 定位数据（K230 → PC, TCP JSON）

```json
{"T": 200, "x": 1.2345, "y": 0.5678, "valid": true, "t": 12345}
```

| 字段 | 说明 |
|------|------|
| T | 消息类型（200=定位） |
| x, y | UWB 坐标（米） |
| valid | 定位是否有效 |
| t | 时间戳（ms） |

### 视频传输（K230 → PC, UDP 分片）

每帧 JPEG 数据按 1400 字节分片，每片带 6 字节包头：

```
[frame_id:2][total_chunks:2][chunk_id:2][JPEG payload]
```

所有字段均为 `unsigned short`（大端序）。

## 常见问题

**Q: 窗口上下弹跳 / 高度变化**
A: 视频标签在布局中未固定高度。在 `main_window.py` 中给 `video_window` 添加 `setFixedHeight(440)` 或在 `setPixmap` 时固定缩放尺寸。

**Q: 视频不显示，只显示"等待视频连接..."**
A: 检查网络连通性，确认 `test.py` 或 K230 是否正确发送到电脑 IP 的 8080 端口。

**Q: TCP 连接超时**
A: 确认 K230 的 TCP 服务端已启动，IP 地址配置正确，同一网段且无防火墙阻拦。
